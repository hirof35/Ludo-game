🎲 Ludo: Dynamic Dice & Anarchy Mode
Pygameで構築された、1人プレイ用の古典的ボードゲーム「Ludo（ルド）」の拡張カスタマイズ版です。公式のブロックルールをベースにしつつ、一発逆転が頻発するエキサイティングなローカルルールや、演出強化されたサイコロアニメーション、3段階のCPU難易度選択システムを搭載しています。

🚀 主な機能と特徴
1. 💥 大逆転・アナーキー戦闘ルール
一網打尽システム: 移動したピッタリのマス（着地マス）に敵のコマが何個重なっていようが、全員まとめて一撃でベース（初期位置）へ叩き落とすことができます。

通過ブロック機能: サイコロの目で「通り過ぎる途中」のマスに敵のコマが2個以上重なっている場合は、強力な「壁」となりそこをまたいで進むことはできません。

🎬 2. ダイナミック・サイコロ演出
サイコロを振った際、出目がパラパラと高速でシャッフルされるローカルロールアニメーションを搭載。

1の目は赤く大きく、他の目は黒いドットで正確に描画される専用のグラフィックレンダラーを実装。

🤖 3. 3段階のCPU難易度設定
起動時のメニュー画面で、プレイスタイルに合わせた難易度を選択可能です。

EASY: CPUは動かせるコマを完全にランダムで選びます（うっかりミス多数）。

NORMAL: 敵を倒せるコマがあれば最優先で狙う、好戦的なバランスです。

HARD: 「6」や「敵をキックできる目」が出やすくなる確率補正に加え、移動先で味方同士を重ねて壁を作る「守り」も計算する最凶AIです。

🏆 4. 明確なゲームクリアルール
自分の4つのコマすべてを中央の三角形（ゴール）に最初に入れたプレイヤーが勝利となります。

ゲームクリア時は画面が暗転し、勝者の色を称えるアワードリザルト画面が大々的に表示されます。

🛠️ 必要環境と実行方法
前提条件
Python 3.x および pygame ライブラリが必要です。

インストール方法
Bash
pip install pygame
実行方法
スクリプトを保存し、以下のコマンドで実行します。

Bash
python ludo_game.py
🎮 操作方法
難易度選択（起動時）

画面中央の「EASY」「NORMAL」「HARD」のボタンをマウス左クリックで選択してゲームを開始します。

プレイヤーのターン（赤色のコマ：RED）

サイコロを振る: 画面を左クリックするとサイコロが回転し、出目が確定します。

コマを動かす: 動かせるコマ（円盤）がある場合、マウスカーソルを合わせて左クリックすることで自動で進みます。

※「6」が出るか、敵のコマをキックするとボーナスターン（もう一度振れる）を獲得します。

CPUのターン（GREEN / YELLOW / BLUE）

選択した難易度システムに基づき、完全自動でサイコロのロールから移動までを高速処理します。

📦 各コード（クラス）の役割
Token: 各コマの個別データ（現在のマス、ベース位置、移動アニメーションキュー、グローバル座標変換）を管理。

GameManager: 共通ルートの生成、移動可否判定（進路上の壁チェック）、キック判定、AI思考ルーチン、勝利判定などのゲームコアロジックを統括。

draw_board(): Ludo専用の15x15マスの幾何学的な盤面、セーフゾーン、ホーム道を毎フレーム描画。

draw_dice(): サイコロの出目（1〜6）をドットパターンで動的レンダリング。
